ગુજરાતી ઘડિયાળ + હોમ સ્ક્રીન વિજેટ (Android)
==============================================

આ એપમાં શું દેખાય છે:
- વાર: સોમવાર, મંગળવાર, બુધવાર ...
- સમય ગુજરાતી આંકડામાં: ૧૦:૩૦
- સવારે / બપોરે / સાંજે / રાત્રે
- તારીખ: ૨૮ ઓક્ટોબર ૨૦૨૬

રંગ, અક્ષરની સાઇઝ, પારદર્શકતા બદલી શકાય છે. વિજેટ નાનું-મોટું કરી શકાય છે.

APK ફાઇલ કેવી રીતે બનાવવી (ફ્રી, કમ્પ્યુટર પર ~૧૦ મિનિટ)
---------------------------------------------------------
૧. આ ZIP ફાઇલ કમ્પ્યુટર પર Unzip (Extract) કરો.
૨. https://github.com પર મફત એકાઉન્ટ બનાવો.
૩. ઉપર જમણે "+" → "New repository" દબાવો. નામ: GujaratiClock. "Public" પસંદ કરો. "Create repository" દબાવો.
૪. "uploading an existing file" પર દબાવો.
૫. Unzip કરેલા GujaratiClock ફોલ્ડરની અંદરની બધી ફાઇલો અને ફોલ્ડર (.github, app, build.gradle,
   settings.gradle, gradle.properties) ખેંચીને (drag કરીને) પેજ પર મૂકો. પછી "Commit changes" દબાવો.
   - જો .github ફોલ્ડર અપલોડ ન થાય: "Add file" → "Create new file" દબાવો, નામમાં
     .github/workflows/build.yml લખો, અને BUILD_WORKFLOW_COPY ફોલ્ડરની build.yml ફાઇલનું લખાણ કોપી-પેસ્ટ કરો. પછી Commit કરો.
૬. ઉપર "Actions" ટેબ દબાવો. ૩-૫ મિનિટ રાહ જુઓ, "Build APK" પાસે લીલું ✔ નિશાન આવે ત્યાં સુધી.
   (જો પૂછે તો "I understand my workflows, go ahead and enable them" દબાવો.)
૭. પૂરા થયેલા Build પર દબાવો → નીચે "Artifacts" માં "GujaratiClock-APK" ડાઉનલોડ કરો.
૮. તેને Unzip કરો. અંદર app-debug.apk ફાઇલ મળશે. એ જ તમારી APK છે.

દાદાના ફોનમાં ઇન્સ્ટોલ કરવી
-----------------------------
૧. app-debug.apk ફાઇલ ફોનમાં મોકલો (WhatsApp, Google Drive કે USB કેબલથી).
૨. ફોનમાં ફાઇલ પર દબાવો. જો પૂછે તો "Install unknown apps" ની પરવાનગી આપો, પછી "Install" દબાવો.
૩. "ગુજરાતી ઘડિયાળ" એપ ખોલો. થીમ અને સાઇઝ પસંદ કરો. પછી "વિજેટ હોમ સ્ક્રીન પર ઉમેરો" દબાવો અને હા કહો.
   અથવા: હોમ સ્ક્રીન પર ખાલી જગ્યાએ લાંબો સમય દબાવો → "Widgets" → "ગુજરાતી ઘડિયાળ".
૪. વિજેટ પર દબાવશો તો સેટિંગ ખુલશે. ખૂણા ખેંચીને સાઇઝ બદલી શકાય.

ધ્યાનમાં રાખો
--------------
- Android 7.0 અને તેથી નવા ફોનમાં ચાલશે. ઇન્ટરનેટ જરૂરી નથી.
- વિજેટ દર મિનિટે બદલાય છે. ફોન સ્લીપમાં હોય તો થોડું મોડું થઈ શકે, સ્ક્રીન ચાલુ થતાં જ સાચો સમય આવી જશે.
- Xiaomi, Oppo, Vivo, Samsung ફોનમાં સમય અટકી જાય તો: Settings → Apps → ગુજરાતી ઘડિયાળ → Battery →
  "Unrestricted / No restrictions" કરો.
- જો Build માં લાલ ✖ આવે, તો લાલ લખાણ કોપી કરીને મને મોકલો, હું સુધારી આપીશ.
